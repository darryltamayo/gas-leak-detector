STEP 2: Upload Code to ESP32
=================================================================

1. Connect ESP32 to your computer via USB
2. Open Arduino IDE
3. Select Board: "ESP32 Dev Module"
4. Select Port: (your ESP32 COM port)
5. Click Upload button
6. Wait for "Done uploading" message

=================================================================
STEP 3: Monitor Serial Output
=================================================================

Open Serial Monitor (Ctrl+Shift+M or Tools > Serial Monitor)
Set baud rate to: 115200

=================================================================
TROUBLESHOOTING
=================================================================

Problem: "WiFi connection failed"
Solution: Double-check WiFi name and password (case-sensitive!)

Problem: "Server connection failed"  
Solution: 
- Verify domain is correct: isu-documentrequest.online
- Check if HTTPS is working in browser
- Try HTTP instead (serverPort = 80, useHTTPS = false)

Problem: "Heartbeat failed - 401 Unauthorized"
Solution: API key mismatch
- Copy exact key from database
- No extra spaces or quotes

Problem: "Heartbeat failed - 404 Not Found"
Solution: Endpoint path is wrong
- Check: /public/api.php?action=heartbeat
- Verify file exists on server

Problem: "SSL certificate verify failed"
Solution: 
- Option 1: Add this line before WiFiClientSecure client:
  client.setInsecure();
- Option 2: Use HTTP instead of HTTPS (less secure)
